# 🦷 Dona Liz - Odontologia Especializada

Landing Page profissional desenvolvida para a **Dona Liz** localizada em Florianópolis - SC. O projeto foi desenhado com foco em estética, saúde bucal e conversão de novos pacientes através de um agendamento facilitado.

## 🚀 Tecnologias Utilizadas

* **HTML5** (Estrutura focada em acessibilidade)
* **Tailwind CSS** (Design System personalizado com foco em cores suaves)
* **JavaScript** (Funcionalidades de navegação e integração com WhatsApp)
* **Vercel** (Hospedagem rápida e segura)

## 🎨 Design System e Identidade

* **Paleta de Cores:** Foco em tons de **Azul Suave, Branco e Prata** para transmitir a sensação de limpeza, tranquilidade e tecnologia clínica.
* **Tipografia:** Escolha de fontes modernas e leves, garantindo que o paciente se sinta acolhido ao ler sobre os tratamentos.
* **Responsividade Total:** Interface otimizada para smartphones, facilitando o agendamento de consultas "on-the-go".

## 🎯 Diferenciais do Projeto

* **Foco no Sorriso:** Galeria de tratamentos e depoimentos estrategicamente posicionados.
* **Agendamento Rápido:** Botão flutuante de WhatsApp para marcação de consultas com um clique.
* **Informação Clara:** Destaque para especialidades e o diferencial de atendimento humanizado na Lagoa.
